# Apex Auto Care

A modern automotive workshop website designed to improve customer acquisition, local search visibility, and service bookings.

## Overview

Apex Auto Care is a portfolio case study representing a professional car workshop in Kuching, Sarawak.

The website focuses on:

* Local SEO
* Mobile-first experience
* WhatsApp lead generation
* Service showcase
* Customer trust building

## Business Objectives

* Increase workshop enquiries
* Improve online visibility
* Simplify customer contact
* Showcase services professionally

## Features

* Responsive design
* WhatsApp integration
* Google Maps integration
* Service catalogue
* Customer testimonials
* Contact forms
* SEO optimized pages

## Pages

* Home
* Services
* About Us
* Testimonials
* Contact

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS

## Project Highlights

* Conversion-focused design
* Local business branding
* Realistic business content
* Professional user experience
* Optimized for mobile devices
